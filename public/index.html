QGIS 导入步骤：

          
1. 打开 QGIS 桌面端，按快捷键 Ctrl + Alt + P 打开内置 Python 控制台（或点击菜单【插件】->【Python 控制台】）。

          
2. 点击下方【复制脚本代码】按钮，将代码粘贴到 Python 控制台并按回车执行。

          
3. 执行后，底图将保存在 QGIS 左侧【浏览器】面板的【XYZ Tiles】或【WMS/WMTS】分类下，可直接拖入画布使用。
