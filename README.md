# QGIS 在线底图服务配置中枢 (QGIS Basemap Hub)

一个开箱即用、轻量且高颜值的 QGIS 在线底图服务与图源配置中枢。提供涵盖天地图、OSM、Esri、高德、腾讯、百度、海图、夜间灯光、地质灾害等百余款空间底图图层检索、实时动态切片预览、多协议解析（XYZ Tiles / WMS / WMTS / Vector Tiles），以及一键生成并导出专属 PyQGIS 自动化导入脚本。

---

## 🌟 核心特性

- **多协议全覆盖**：精准支持标准 XYZ 栅格瓦片、OGC WMS/WMTS 空间数据服务以及高精矢量切片（Vector Tiles / MVT / PBF）。
- **实时切片预览**：内嵌轻量交互式地图引擎，支持一键加载预览图层效果、缩放层级核验与切片坐标漂移诊断。
- **自动化脚本导出**：勾选所需底图后一键生成标准 PyQGIS 脚本，复制至 QGIS 控制台回车即永久注册进 QGIS 浏览器面板。
- **纯标准库驱动**：后端仅基于 Python 3 原生标准库（http.server + sqlite3），零第三方外部重依赖，拉取即跑。
- **隐私友好架构**：全系统遵循极致的数据隐私保护原则，彻底去 IP 化与无 PII 设计。

## 🚀 快速启动

本地需预装 Python 3.8+ 环境：

```bash
# 1. 克隆或下载本仓库至本地
git clone https://github.com/OpenQGIS/maps.git
cd maps

# 2. 启动服务（默认监听本地 8080 端口）
python server.py

# 3. 浏览器访问
http://127.0.0.1:8080
```

如需指定运行端口：
```bash
python server.py 8888
```

## 🔒 隐私与数据安全声明 (Privacy Policy)

本项目致力于提供公开、透明、负责任的开源底图工具。我们在架构层面贯彻执行**“零个人隐私侵犯（No PII）”**设计：

1. **去 IP 化统计**：
   - 系统**绝不采集、不存储、不持久化**任何用户的公网/内网真实 IP 地址。
   - 数据库中的访问统计（PV / UV）完全基于客户端本地生成的随机匿名标识经过单向 SHA-256 离散哈希后的散列串，无法反向推导任何设备或真实自然人信息。
2. **防刷频控的内存瞬时化**：
   - 为抵御恶意爬虫与自动化高频脚本刷量，系统采用内存级滑动窗口频控（RateLimiter）。
   - 访问时的网络连接地址仅在 Python 进程的瞬时内存队列中驻留数秒至数十秒，**从不写入数据库、从不落盘、从不记录到磁盘日志中**。服务进程一旦重启或终止，内存频控记录即刻彻底归零。
3. **点赞与导出推荐量**：
   - 点赞与导出热度统计仅用于社区推荐排行榜，严格遵循数据库级原子唯一约束（一人一票与单日热度去重），杜绝恶意刷分。
